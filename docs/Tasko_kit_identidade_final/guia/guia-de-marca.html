05. Regras de aplicação propostas

Preservar as proporções e a geometria, o losango central e as cores oficiais. Reservar espaço livre externo de pelo menos 1/4 da largura do símbolo. Usar preferencialmente a assinatura horizontal a partir de 160 px, a vertical a partir de 120 px e o símbolo a partir de 32 px. Em favicons menores, verificar a legibilidade no navegador. Não esticar, aplicar degradês, sombras ou alterar as cores.

As dimensões mínimas e áreas de respiro são recomendações de design, não requisitos originais do projeto. Para textos de interface, verificar contraste WCAG AA conforme o fundo e o tamanho; as cores de destaque não garantem contraste suficiente em qualquer combinação.

06. Implementação

Use os SVGs transparentes para site, Figma e documentos. PNGs para aplicações raster. A pasta web inclui favicons, ícones PWA comuns e maskable, CSS de cores e um exemplo de manifest. Ajuste os caminhos do manifest à estrutura do projeto.
